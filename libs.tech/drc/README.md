# ICsprout55 DRC (KLayout)

DRC runset for the released ICS55 libraries, structured after the IHP SG13G2
(130 nm) modular deck and the FreePDK45 (45 nm) KLayout deck.  This is a port
of the iDRC check set (Mulan PSL v2, openecos-projects/ecc-tools) to the
KLayout DRC language.

**Not a foundry DRC deck** — the foundry DRC rule deck is not released.  Every
rule value carries a provenance tag in `rule_decks/ics55_rules.json`:

- `lef`  — exact tech-LEF value (`prtech/techLEF/N551P6M.lef`), BEOL;
- `gds`  — measured from the released std-cell / IO GDS
  (`measurements_*.json`, regenerated by `tools/measure_gds.rb`), FEOL;
- `derived` — placeholder / approximation, NOT foundry data (advanced rules,
  antenna).

## Layout

```
ics55_drc.drc            main deck (source/report/switches/rules + module assembly)
rule_decks/
  ics55_rules.json       rule values + provenance
  layers_def.drc         layer + derived layers (nact/pact/gates)
  feol/01_wells.drc      NW, IOWELL
  feol/02_active.drc     ACT, IOACT
  feol/03_poly.drc       POLY, gates, PPO
  feol/04_implant.drc    NP, PP, LVTN/LVTP/HVTN/HVTP, ESD
  feol/05_cont.drc       CT
  beol/06_metal.drc      M1..M5, T4M2
  beol/07_via.drc        V1..V4, T4V2, RV
  beol/08_pad.drc        PADM, ALPAD
  geometry/09_grid.drc   manufacturing grid (1 nm)
  advanced/10_eol_jog.drc  EOL / MinStep / gate overhang / jog / 45° (derived)
  density.drc            window density: POLY 12-55% (10um), ACT 20-65% (20um),
                         M1 20-70% (20um), M2-M5 empirical (20um); skipped on
                         layouts smaller than the tile size (no per-cell runs)
  antenna.drc            antenna checks (disabled by default)
tools/measure_gds.rb     GDS rule-value measurement (per-cell, library min)
measurements_*.json      measured values (H7CR/H7CL/H7CH/IO)
```

## Usage

```sh
klayout -b -r ics55_drc.drc -rd input=<layout.gds> \
    [-rd top=<cell>] [-rd report=<out.lyrdb>] \
    [-rd no_feol=true] [-rd no_beol=true] [-rd no_advanced=true] \
    [-rd antenna=true] [-rd no_grid=true] [-rd tables=feol] [-z]
```

Switches: `tables` (subset selection), `no_*` (disable families),
`antenna` (enable antenna - values TBD), `run_mode` (deep/flat/tiling).

## Rule sources

- BEOL rules are exact LEF values (width/spacing/area/min-enclosed-area for
  metals; width/spacing/enclosure/array-spacing for vias).
- FEOL rules are measured from the released libraries: std-cell minima for
  ACT/NW/POLY/NP/PP/CT/M1 and gate length; IO minima for IOACT/ESD/IOWELL/
  PADM/ALPAD.  CT/M1/V1/TM2 measurements corroborate the LEF values.
- Measured minima bound the drawn (foundry-clean) geometry; they are NOT
  foundry rule values.

## Port notes (iDRC -> KLayout)

KLayout's DRC engine has no native EOL-spacing, jog-spacing, corner-fill or
MinStep primitives (verified against 0.30.x; `space(min, eol(...))` is not
available in 0.30.9).  The advanced module (`advanced/10_eol_jog.drc`) runs
the derived checks on *cleaned* layers (snap to the 1nm grid + smooth +
clean, which removes the grid-snapping/binarization jogs):

| iDRC check | KLayout implementation |
|---|---|
| min width / spacing / area | `.width()/.space()/.with_area()` |
| min hole area (MinHole) | `.holes.with_area()` |
| via enclosure | `.enclosing()` both sides |
| notch spacing | `.notch()` |
| cut spacing / diff-layer cut | `.space()/.sep()` on cut layers |
| off-grid | `.ongrid(0.001)` |
| MinStep | `.edges.with_length(0, min_step)` on cleaned layers (0.03 um placeholder) |
| EOL spacing | line-end edges (<= eol_len) `.sep()` to all edges on cleaned layers (edge-based; `space(min, eol(...))` not in 0.30.9) |
| gate overhang | gate-edge zones `extended_out/in` vs poly/active, direction-specific (poly: channel dir 0.06 um placeholder; active: L dir 0.14 um measured); sub-0.004 um^2 step-slivers dropped |
| antenna | `antenna_check()` (values TBD, off by default) |
| short circuit | covered by the LVS deck, not GDS DRC |
| jog spacing | intra-polygon `.notch()` approximation |
| corner-fill / MinStep adjacency | no KLayout primitive |
| density | `.without_density(min, max, tile_size(...))` (POLY 12-55% @10um, ACT 20-65% @20um, M1 20-70% @20um; M2-M5 empirical IO-cell bounds @20um); skipped on layouts smaller than the tile |

## New checks (this round)

- **Antenna** (enabled by default, `-rd no_antenna=true` to disable): gate-to-
  metal antenna ratio via the built-in connect() topology (POLY->CT->M1->...->
  M5); ratio 300 placeholder.  The same connectivity flags PAD-to-gate shorts
  (a PAD connected straight to a gate is a huge antenna) - the dedicated
  PAD/ESD-path rule is LVS-side.
- **MOM** (marker-based, vacuous without layers): MOM_MARKER 60/1, DUMMY 60/2,
  NO_FILL 60/3, DM_EXCEL 60/4.  `m2_in_mom` width/spacing (LEF values), dummy
  inside the marker+margin exclusion, NO_FILL/DM_EXCEL coverage of the
  exclusion zone.  Enable/disable with `-rd no_mom=true`.
- **Min corner / min adjacency** (advanced module, empirical 0.03/0.05):
  edges < 0.03um (min corner), corners closer than 0.05um (corner adjacency),
  short-edge-to-corner and notch-edge-to-concave-corner adjacencies.
- **Wide metal slots** (BEOL): metal with bbox min-dim > 20um and no holes
  flagged (CMP slots; placeholder).
- **EM via ports** (BEOL): isolated vias on metal wider than 10um flagged
  (needs 2x2/3x3 arrays; placeholder).  EM current limits are post-layout
  simulation, not DRC.

## Cell exclusion for real-GDS runs (analog / interconnect focus)

KLayout 0.30.9 has no `forget_cell`/`cells()` DRC API, so the std-cell
content is excluded via the drawn BOUNDARY layer (191/12, present in the
released std-cell GDS): with `-rd cell_exclusion=true` the interior of every
boundary (shrunk by `cell_excl_margin`, 0.1 um placeholder) is subtracted
from all checked layers, so the DRC checks the top-level interconnect and
analog shapes only.  The margin band keeps the shapes crossing the cell
frames.  Std-cell verification runs leave this OFF (per-cell flags are the
point there); enable it on real analog/interconnect GDS.

## Analog signoff (logged, NOT implemented yet - to be checked later)

- Gate orientation must be uniform (no vertical/horizontal mix -> mu0 and
  Vth mismatch).
- SA/SB matching with dummy poly.
- WPE-sensitive analog: identical SCA/SCB/SCC distance to the N-well,
  > 1.5-2.0 um.
- Maximum tap distance (PMOS to N-well tap, NMOS to P-sub tap) below the
  latch-up limit for large currents.
- P-tap / N-well guardrings between high-frequency / large-power modules and
  sensitive modules.
- Contacts densely filled without missing ones.
- Deep N-well isolation of the sensitive analog P-sub from the global digital
  P-sub; check the P-sub distance and enclosure.

## Disabled checks (2026-09-25, user call)

The following checks are commented out in the rule modules.  Their values and
provenance stay in `ics55_rules.json`; re-enable by uncommenting.

| Check | Module | Reason |
|---|---|---|
| `cont.ct.enc.m1` | `feol/05_cont.drc` | LEF `ENCLOSURE ABOVE 0.04` flags every released std cell (the cells draw a uniform 0.025 um CT-to-M1 top enclosure).  The official Calibre deck has NO plain CT-to-M1 enclosure rule (only the seal-ring CT bar, SRCK_14a_CT 0.375) — the check is the LEF router constraint, stricter than the foundry DRC. |
| `adv.<layer>.eol` (all layers) | `advanced/10_eol_jog.drc` | Placeholder approximation (no official line-end rule ported; the official MET1_S_5 covers only the dense line-end configuration) — flags the foundry-drawn jog steps. |
| `adv.m1.notch`, `adv.m2.notch` | `advanced/10_eol_jog.drc` | Placeholder jog/notch approximation — flags the foundry-drawn intra-polygon jog pairs. |
| `adv.gate.act_overhang` | `advanced/10_eol_jog.drc` | The gate definition (poly over ACT) includes the 0.32 um power straps.  The official PO_EX_2 (0.14) applies to the channel-length gates only (the official gate selection is `LENGTH GATE_core_W < 0.12`); the straps' 0.065 um ACT extension (SDFFNRX2H7R) is NOT a design problem. |

## Known limitations

- The advanced (derived) checks run on cleaned layers but the EOL and jog
  (notch) approximations still report a handful of flags on foundry-clean
  cells: the released cells draw 30-100nm jog steps inside M1/poly routing,
  and the edge-based EOL (line ends <= eol_len .sep to all edges) and
  `.notch()` pick up those intra-polygon jog pairs.  Values are placeholders
  (`derived` provenance); they are not foundry rules.
- CT enclosure by POLY/ACT uses measured floors (0.01) — the LEF only
  specifies the M1-side (ABOVE) enclosure.
- CT enclosure by M1 (`cont.ct.enc.m1`, LEF 0.04 ABOVE) flags every released
  std cell: the cells draw a uniform 0.025um CT-to-M1 top enclosure (interior
  and boundary contacts alike).  The official Calibre deck has NO plain
  CT-to-M1 enclosure rule (only the seal-ring CT bar, SRCK_14a_CT 0.375), so
  the LEF-based check is stricter than the foundry DRC by design — keep as the
  LEF router constraint, not a DRC waiver.
- The width/space/sep checks lack the official `ABUT<90 SINGULAR REGION`
  qualifier (Calibre INT/EXT): the port flags the 90-degree notch and
  colocated-edge configurations the official rules waive.  Observed on
  SDFFNRX2H7R: the well-tap cutouts create a 0.36um well sliver
  (`well.nw.width` 0.47, official NW1_W_1 0.47 ABUT<90) and the poly straps
  carry 0.065um ACT extensions (`adv.gate.act_overhang` 0.14, official
  PO_EX_2 0.14 with EXT<0.002 ABUT==90 qualifier).  The ported checks are
  stricter than the official in these configurations; values are the official
  numbers.
- `poly.poly_act.sep` uses a 0.001um floor (universal-DRC range) to exclude
  the colocated gate-overhang edge pairs the official PO_S_11
  (EXT AA PO < 0.05 ABUT<90) waives — the plain sep() flagged every gate
  (76+ pairs per cell).  Fixed 2026-09-25.
- Poly/diffusion gate overhang is implemented in the advanced module
  (adv.gate.poly_overhang / adv.gate.act_overhang, direction-specific via
  gate-edge zones) with placeholder / measured values (provenance: derived)
  - not foundry rules; see the port-notes table above.
- Standalone cells flag boundary CT-enclosure / poly-active separations that
  are satisfied by neighbor abutment in a real placement; run on the placed
  chip, not single cells.
